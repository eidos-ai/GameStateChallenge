# GameState Challenge by SoccerNet
This repository was created to solve the challenge proposed by SoccerNet. The challenge itself requirest to create a game state from a set of labels (json files) generated using computer vision.
The eidos template was used to create this repository, so Black (code linting) and MyPy (static code typing) are used and checked through Github actions.

## Installation
In order to run the code, you first need to clone the repository and its submodules. To do so, run the following command:


```git clone --recurse-submodules https://github.com/eidos-ai/GameStateChallenge.git```

After cloning it, you need to create the virtual environment and install its submodules. To do so, run the following commands:

```conda create -n GameStateChallenge pip python=3.10 pytorch==1.13.1 torchvision==0.14.1 pytorch-cuda=11.7 -c pytorch -c nvidia -y ; conda activate GameStateChallenge ; cd src/sn-gamestate ; pip install -e . ; cd ../tracklab ; pip install -e . ; mim install mmcv==2.0.1 ; cd ../../ ; pip install -e . ```

Lastly, install its requirements:

```pip install -r requirements.txt```

## Data download
SoccerNet provides a package with a downloader to get the data. To download the data, run the following command:

```python src/download_data.py```

The previous command will open a terminal tab showing the current download progress. The data will be downloaded to the `data` folder (autogenerated). After is finished, the next step is to unzip the full dataset. To do so, run the following command:

```cd data/SoccerNetGS
unzip gamestate-2024/train.zip -d train
unzip gamestate-2024/valid.zip -d valid
unzip gamestate-2024/test.zip -d test
unzip gamestate-2024/challenge.zip -d challenge
cd ../..
```

### Dataset reformat into YOLOv8 format
The dataset is provided in a format that is not compatible with the YOLOv8 model. To reformat the dataset, run the following command:

```python src/yolov8/yolov8_dataset_reformatter.py -rdp data/SoccerNetGS/gamestate-2024 -ydp data/YoloDataset```

At this point:
- the repository and its submodules were cloned,
- the virtual environment was created and activated,
- the requirements were installed,
- the data was downloaded and unzipped,

so, you are ready to run the code.

## Running the code
To run the code, you need to run the following command:

```python -m tracklab -cn custom_config```
