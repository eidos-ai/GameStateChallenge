## model_run.py
This script is used to run the model inference on the data and generate one .npz file per given video, containing:
- the model path (.pt file),
- embeddings,
- and its corresponding annotation_id.

The script takes the following **required** arguments:
- `--model_path` (str): path to the model file (.pt).
- `--data_path` (str): path to the train, test or valid data directory.

An example of a command to run the script is:
```python model_run.py -m /home/francisco/GameStateChallenge/experiments/identifier/GAM-156/GAM156-epoch0.pt --data_path ../data/SoccerNetGS/train --mlp_output_size 256 --games_list SNGS-060 SNGS-061 SNGS-062```

## magic_kmeans_clustering.py
This script is used to run a self-called Magic KMeans clustering algorithm on the embeddings generated by the model. We call it "Magic" because we are hardcoding the number of clusters per video, based on the number of role_id present in the video.
It also provides the option to save the clustering results in a .json file (one file per video).

The script takes the following **required** arguments:
- `data_path` (str): path to the train, test or valid data directory.

A key argument, but not required, is:
- `mlp_output_size` (int, default=512): output features size for the MLP.

An example of a command to run the script is:
```python magic_kmeans_clustering.py --data_path ../../data/SoccerNetGS/train --videos_list SNGS-060```

## clustering_accuracy_evaluation.py
This script is used to evaluate the clustering results generated by the Magic KMeans algorithm. It calculates the clustering accuracy (per video: overall and per class, and average: of overalls, of per class).

The script takes the following **required** arguments:
- `--data_path` (str): path to the train, test or valid data directory.

An example of a command to run the script is:
```python clustering_accuracy_evaluation.py --data_path ../../data/SoccerNetGS/train --videos_list SNGS-060 SNGS-061 SNGS-062```

## dbscan_clustering.py
This script is used to run the DBSCAN clustering algorithm on the embeddings generated by the model. It also provides the option to save the clustering results in a .json file (one file per video).

The script takes the following **required** arguments:
- `--data_path` (str): path to the train, test or valid data directory.

#### DBSCAN arguments:
- `--eps` (float, default=0.5): The maximum distance between two samples for one to be considered as in the neighborhood of the other.
- `--min_samples` (int, default=5): The number of samples in a neighborhood for a point to be considered as a core point.

An example of a command to run the script is:
```python dbscan_clustering.py --data_path ../../data/SoccerNetGS/train --videos_list SNGS-060 SNGS-061 SNGS-062 --eps 3 --min_samples 3```

## dbscan_evaluation.py 
This script is used to evaluate the clustering results generated by the DBSCAN algorithm. It counts the number of predicted clusters per video, and calculates the homogeneity and completeness scores (per video and average across all videos).

The script takes the following **required** arguments:
- `--data_path` (str): path to the train, test or valid data directory.

An example of a command to run the script is:
```python dbscan_evaluation.py --data_path ../../data/SoccerNetGS/train --videos_list SNGS-060 SNGS-061 SNGS-062```

## random_forest_classification_model.py 
This script is used to run a Random Forest Classification Model which its input are extracted features as average position, number of tracks in cluster, etc. The output is measured using the model metrics and the ultimate goal is to use the KMeans number of clusters with the best accuracy.

The script takes the following **required** arguments:
- `--data_path` (str): path to the train, test or valid data directory.

An example of a command to run the script is:
```python random_forest_classification_model.py --data_path ../../data/SoccerNetGS/valid --videos_list SNGS-021 SNGS-039 SNGS-078```
